# Лендинг Hop to Olympus

Продающая страница игры. Лежит на главной `/`, кнопка «Играть» ведёт на `/play/`, где живёт сама игра.

Идея: одна живая 3D-сцена, а скролл ведёт камеру вниз. Камера спускается с рассвета над облаками, проходит сквозь облака к островам-мирам, мимо сцен с механиками к дому с Кумо и на закат с финальной кнопкой.

## Две версии

| Адрес | Версия |
|---|---|
| `/` (`index.html`) | Основная: тёплое небо, четыре мира в карусели, шесть сцен механик |
| `/action.html` | Экшен: ночь и гроза, молнии, титан за героем, все шесть миров по очереди, у каждого свои враги, три боевые механики |

Обе страницы работают на одном `app.js`. Экшен-версия включается настройками `window.HTO_CFG` в `action.html`: `night`, `stack`, `action`, свои файлы миров и механик, свои тексты. Стили поверх основных лежат в `landing/action.css`.

## Звук

Звук по умолчанию выключен: браузеры не дают включить его без клика. Кнопка «Включить звук» есть на первом экране и в шапке. После включения играет генеративная музыка, при прокрутке шуршит ветер, внутри облаков слышен воздушный гул, между секциями звенит колокольчик, в экшен-версии гремит гром.

## Как запустить

```bash
node server/server.js
# лендинг: http://localhost:8080/
# игра:    http://localhost:8080/play/
```

Сборки нет. Three.js r128, GSAP 3.12.5 и Lenis 1.1.13 подключаются с CDN. Выкладывается так же, как игра: на тот же сервер или любой статический хостинг. Конфиги грузятся через `fetch`, поэтому страницу нужно открывать через сервер, а не двойным кликом по файлу.

## Как добавить мир

Допиши объект в `landing/data/worlds.json`:

```json
{ "id": "dome", "theme": "olympus", "color": "#9fb8ff",
  "name": { "ru": "Звёздный купол", "en": "Star Dome" },
  "biome": { "ru": "…", "en": "…" },
  "desc": { "ru": "…", "en": "…" },
  "features": { "ru": ["…"], "en": ["…"] } }
```

Остров для карусели строится сам. `theme` выбирает вид острова: `islands`, `olympus`, `horai`, `abyss` или `home`. Новый вид добавляется в `THEMES` и в функцию `island()` в `voxel.js`.

## Как добавить механику

Допиши объект в `landing/data/mechanics.json`. Поле `scene` — одна из готовых сцен: `jump`, `fight`, `boss`, `craft`, `home` или `coop`. Новая сцена описывается в `station()` и анимируется в `updStations()` в `app.js`. Карточка с текстом, остановка камеры и позиция острова на спуске появятся сами.

## Как обновить роадмап

Правь `landing/data/roadmap.json`. Поле `status` принимает значения `done`, `progress` или `next`.

## Тексты и языки

Все строки интерфейса лежат в `I18N` в начале `app.js` (RU и EN). Тексты миров, механик и роадмапа берутся из JSON. Язык выбирается по браузеру и запоминается после переключения.

## Доступность и производительность

- `prefers-reduced-motion`: без плавного скролла, камера переключается без инерции, нет ветра и анимаций появления.
- Карусель миров работает с клавиатуры (стрелки) и с кнопок.
- Весь текст — настоящий HTML поверх canvas.
- Облака, острова и частицы собраны через `InstancedMesh`: по одному вызову отрисовки на облачный слой и на остров. Плотность ограничена через `pixelRatio`, на телефонах облаков и частиц меньше. Далёкие сцены механик не рисуются.
