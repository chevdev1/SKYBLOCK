# Hop to Olympus · Прыг на Олимп

Воксельный платформер-RPG в браузере: прыгай с яруса на ярус, собирай снаряжение, побеждай боссов и поднимайся в Царство богов.

**Альфа-версия 2.10 — плейтест.**

## Как запустить

Игра — один файл `index.html` на Three.js (r128 с CDN). Достаточно открыть его в браузере или выложить на любой статический хостинг (GitHub Pages, Netlify, Vercel). Без сервера всё работает, но рекорды и карты Мастерской хранятся только на устройстве игрока.

С сервером (общие таблицы рекордов, каталог карт, лайки и звёзды создателей):

```bash
node server/server.js
# открыть http://localhost:8080
```

Сервер без зависимостей, нужен только Node 18+. Данные лежат в `server/data.json` (он в `.gitignore`). Порт и файл можно поменять: `PORT=3000 DB_FILE=/data/oblaka.json node server/server.js`.

Если игра лежит на GitHub Pages, а сервер отдельно, укажи адрес сервера в `index.html` в теге `<head>`:

```html
<meta name="oblaka-api" content="https://твой-сервер.example.com">
```

## Что внутри

- 5 ярусов обычного мира и 4 яруса Царства богов, флажки-чекпоинты, телепорт между ними.
- Ритмичные прыжки до мега-прыжка, крылья, крюк-кошка, рывок и двойной прыжок.
- Мобы с добычей, крафт снаряжения (меч, коса, броня, сапоги, крылья), сумка на 36 ячеек.
- Боссы: серафим, два мини-босса в подземельях, три босса в логовах Царства богов, Зевс на вершине Олимпа (с него падает Венец громовержца, мега-прыжок с ним бьёт молниями).
- Разлом Хаоса за Олимпом: три тёмных яруса, тени, стражи времени и ужасы Тартара, боссы Никта и Кронос с аниме-атаками (лазеры, волны-полумесяцы, остановка времени). Награды: Крылья ночи и Коса Кроноса.
- Уровни и опыт: каждые 5 уровней дают сердце здоровья.
- NPC с заданиями, смена дня и ночи, гонки на время с призраком.
- Питомец-висп уникального цвета, управляется стрелками.
- Редактор карты с экспортом и импортом.
- 31 достижение с всплывающими карточками, экран «Достижения и рекорды» (T) с таблицами: очки достижений, мобы, PvP, создатели карт и пять забегов.
- Миникарта в углу и объёмная 3D-карта мира (N или нажать на миникарту): флажки, боссы, задания, телепорт к открытым флажкам.
- Мастерская: игроки строят свои карты (старт, финиш, чекпоинты, заливка), проходят тест, публикуют, ставят лайки, соревнуются на таблице рекордов каждой карты. Создатели получают звёзды и уровни.
- Сенсорное управление: плавающий джойстик, кнопки прыжка, удара, рывка и крюка, щипок для приближения камеры. Включается само на телефонах, на компьютере — в Настройках → Управление.
- Настройки графики, звука и управления, русский и английский язык.

| G H J K L | эмоции |

| B | редактор |

## Мастерская

Карты игроков строятся в отдельной области неба (x = −600). Основной мир сохраняется и возвращается после выхода. Порядок: «Мастерская» → «Мои карты» → «Создать карту» → заготовка → стройка → «Тест» → «Опубликовать». Опубликовать можно только карту, которую автор сам прошёл.

Без сервера опубликованные карты видны только на этом устройстве, а друзьям их можно передать кодом (`OBL1:…`, кнопка «Код»). С сервером карты попадают в общий каталог.

Звёзды создателя: +1 за каждого нового игрока, +2 за каждого дошедшего до финиша, +5 за лайк. Свои прохождения не считаются. Как это развивать дальше — в [docs/WORKSHOP.md](docs/WORKSHOP.md).

## API сервера

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | проверка, что сервер жив |
| GET | `/api/scores?board=…&me=uid` | таблица: `ach`, `kills`, `pvp`, `creators`, `race-0…4`, `map-<id>` |
| POST | `/api/scores` `{uid,nick,board,v}` | отправить результат |
| GET | `/api/maps?sort=popular\|new&me=uid` | каталог карт |
| GET | `/api/maps/<id>` | карта целиком |
| POST | `/api/maps` `{uid,nick,id?,name,desc,th,data}` | опубликовать или обновить свою карту |
| POST | `/api/maps/<id>/play\|like\|finish` | игрок открыл, лайкнул, прошёл (с `t` — время) |
| GET | `/api/creators/<uid>` | статистика и звёзды создателя |

`uid` — случайный ключ игрока из `localStorage` (`oblaka-uid`). Сервер никому не отдаёт чужие uid, только флаги `me` и `own`. Это защита на время плейтеста, а не настоящий вход: перед реальными наградами нужна авторизация (см. docs/WORKSHOP.md).

## Онлайн и PvP

Чат, видимость других игроков и PvP работают двумя способами:

- через свой сервер: `node server/server.js`, игроки заходят по адресу компьютера в сети, например `http://192.168.1.5:8080` (сервер печатает адреса при запуске). Связь идёт по WebSocket на `/ws`, до 32 игроков, при обрыве игра сама переподключается;
- через канал реального времени Claude (`window.claude.use('room')`), когда игру открывают по ссылке в Claude.

Без сервера и без Claude игра работает в одиночном режиме. Сообщения комнаты:

- presence: позиция, скин, оружие, PvP-флаг, здоровье, цвет виспа, `bf` — с каким боссом игрок сейчас бьётся;
- `chat` `{n, t}`;
- `sw` `{t}` — взмах оружием;
- `hit` `{to, d, x, z, n}` — попадание в PvP;
- `ko` `{k, v}` — кто кого выбил;
- `bst` `{b, p, r, m, hp, …}` — состояние босса от ведущего боя (10 раз в секунду);
- `bfx` `{b, l}` — атаки босса у ведущего, остальные их повторяют;
- `bhit` `{b, d, to}` — удар по боссу, отправленный ведущему;
- `bdead` `{b}` — босс побеждён, каждый участник получает добычу;
- `shit` — общий удар по серафиму.

Ведущим в бою становится игрок с наименьшим id среди тех, кто сейчас бьётся с этим боссом.

## Сохранения

Прогресс, карта, сумка, настройки и рекорды хранятся в `localStorage` браузера (ключи `oblaka-*`). Достижения лежат в прогрессе (`oblaka-progress-v1` → `ach`), карты Мастерской — в `oblaka-ws-mine` (свои) и `oblaka-ws-lib` (полученные по коду).

# Hop to Olympus (English)

A voxel platformer RPG in the browser. Climb tier by tier, craft gear, beat bosses and ascend to the Realm of the Gods.

**Alpha 2.10 — playtest.** Open `index.html` in a browser or host it on any static host. Switch the language to English in Settings (O). Run `node server/server.js` for shared leaderboards and the Workshop map catalog.
