# Облачные острова / Cloud Islands

Воксельный платформер-RPG в браузере: прыгай с яруса на ярус, собирай снаряжение, побеждай боссов и поднимайся в Царство богов.

**Альфа-версия 2.1 — плейтест.**

## Как запустить

Игра — один файл `index.html` на Three.js (r128 с CDN). Достаточно открыть его в браузере или выложить на любой статический хостинг (GitHub Pages, Netlify, Vercel).

Для локальной разработки удобнее поднять простой сервер:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## Что внутри

- 5 ярусов обычного мира и 4 яруса Царства богов, флажки-чекпоинты, телепорт между ними.
- Ритмичные прыжки до мега-прыжка, крылья, крюк-кошка, рывок и двойной прыжок.
- Мобы с добычей, крафт снаряжения (меч, коса, броня, сапоги, крылья), сумка на 36 ячеек.
- Боссы: серафим, два мини-босса в подземельях, три босса в логовах Царства богов.
- NPC с заданиями, смена дня и ночи, гонки на время с призраком.
- Питомец-висп уникального цвета, управляется стрелками.
- Редактор карты с экспортом и импортом.
- Настройки графики, звука и управления, русский и английский язык.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | бег (работает на любой раскладке) |
| Пробел | прыжок, в воздухе — полёт на крыльях |
| Shift | рывок (SERGIO) |
| ЛКМ / ПКМ | удар и копание / поставить блок |
| 1–9, Q, I | быстрые ячейки, выбросить, сумка |
| E | крюк-кошка |
| Z | сменить оружие |
| Стрелки | управлять виспом |
| P | PvP вкл/выкл |
| C | крафт |
| F | поговорить с NPC |
| G H J K L | эмоции |
| Enter | чат |
| B | редактор |
| O | настройки |

## Онлайн и PvP

Сейчас чат, видимость других игроков и PvP работают через встроенный канал реального времени Claude (`window.claude.use('room')`), то есть только когда игру открывают по ссылке в Claude. В обычном браузере игра работает в одиночном режиме.

Чтобы онлайн заработал на своём сайте, нужно заменить слой `NET` (поиск по `/* online: chat and other players */`) на свой сервер, например WebSocket. Сообщения уже простые:

- presence: позиция, скин, оружие, PvP-флаг, здоровье, цвет виспа;
- `chat` `{n, t}`;
- `sw` `{t}` — взмах оружием;
- `hit` `{to, d, x, z, n}` — попадание в PvP;
- `ko` `{k, v}` — кто кого выбил.

## Сохранения

Прогресс, карта, сумка, настройки и рекорды хранятся в `localStorage` браузера (ключи `oblaka-*`).

# Cloud Islands (English)

A voxel platformer RPG in the browser. Climb tier by tier, craft gear, beat bosses and ascend to the Realm of the Gods.

**Alpha 2.1 — playtest.** Open `index.html` in a browser or host it on any static host. Switch the language to English in Settings (O).
