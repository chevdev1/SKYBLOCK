# Changelog

## 2.1 alpha
- WASD работает на любой раскладке клавиатуры (физические клавиши вместо букв).
- Висп держится рядом с героем (радиус 4.5), у каждого игрока свой случайный цвет.
- PvP-режим (P): оружие горит красным, удары по игрокам с включённым PvP, лента побед в чате, счёт побед и поражений.
- Без PvP оружие убирается за спину и появляется в руке при ударе.
- Камера сама разворачивается за спину героя при беге (можно выключить в настройках).
- Меню настроек, английская версия, наполнение Царства богов, боссы в логовах, висп.
