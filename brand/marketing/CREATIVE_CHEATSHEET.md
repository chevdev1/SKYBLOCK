# Шпаргалка Claude: как делать креативы Hop to Olympus

Этот файл для меня. Перед каждым креативом: прочитать, следовать, обновить, если нашёл новое правило.

## 1. Процесс (всегда в таком порядке)

1. Взять из `COPYWRITER_BRIEF.md` текст поста и номер.
2. Выбрать **реальный кадр игры** (не лендинг, не выдумка): `brand/refs-game/` или новый, снятый скриптом ниже.
3. Сделать HTML-шаблон `src/post-NN.html` по образцу `post-01.html`: фон, слой читаемости, текст.
4. Рендер: `node src/render.js src/post-NN.html creatives/post-NN-en-1600x900.png 1600 900 en 1`, затем `ru`.
5. **Посмотреть результат глазами**: читается ли на 600 px по ширине (так показывает X в ленте), нет ли чужих надписей в кадре, не режутся ли буквы.
6. Закоммитить и запушить, открыть папку пользователю.

## 2. Форматы

| Назначение | Размер | Заметки |
|---|---|---|
| Пост X, картинка 16:9 | 1600×900 | основной. Текст в центральных 90% |
| Пост X, квадрат | 1080×1080 | для карусели и IG |
| Шапка X | 1500×500 | текст по центру, слева аватар закрывает ~1/3 снизу |
| Вертикаль (Reels, Shorts) | 1080×1920 | текст в средних 70% по высоте |
| Open Graph | 1200×630 | для ссылок на сайт |

Для ретины рендерить с `scale=2`.

## 3. Дизайн-система

- **Палитра:** индиго `#141a3c` (чернила), золото `#ffc23c`, розовый `#ff5d8a`, белое облако `#f4f8ff`, закат `#f48fba` → `#ffe9c2`, зелёный индикатор `#2fbf4a`.
- **Шрифты:** заголовки Pixelify Sans 700, подписи и теги Press Start 2P, основной текст Nunito 900 (все с Google Fonts).
- **Заголовок:** белый, тонкая обводка 3-4 px цветом `#141a3c`, жёсткая тень вниз 8-11 px. Акцентное слово золотое.
- **Плашки:** фон `#141a3c`, скругление 8-10 px, жёсткая тень без размытия. Теги золотые с обводкой 4-5 px и тенью 6 px.
- **Слой читаемости:** градиент `#141a3c` слева 0.82 → 0 к 62% ширины; виньетка по краям 0.28.
- **Логотип:** Кумо без фона `brand/logo/kumo-logo-256.png` слева вверху рядом с «Hop to Olympus».
- **Стиль без сглаживания:** кубы и пиксельные текстуры оставляем резкими, фото-эффектов не добавляем.

## 4. Источники кадров

- Игра: `play/` через Playwright. Скрипт съёмки без интерфейса: `brand/marketing/src/capture-game.js`.
- Эталоны: `brand/refs-game/` (герой анфас, герой в прыжке со спины, острова, Кумо).
- Кумо без фона: `brand/logo/`.
- Боссы, арсенал: `landing/img/bosses/`, `docs/screens/`.
- Правило: **в кадре не должно быть надписей игры на другом языке** (подписи NPC, «Забег на время»). Если есть, выбрать другой кадр или другой угол.

## 6. Рамки честности

- Нет доходности, тикера, «заработка», цен, «бесплатно навсегда».
- Дефицит только настоящий. Для «скоро» писать «Alpha test: opening soon».
- Цифры только из проекта: 6 миров, 33 босса, 12 видов оружия, до 32 игроков, шанс 1%.
